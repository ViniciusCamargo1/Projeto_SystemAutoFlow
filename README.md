SystemAutoFlow - Automação de Relatórios de Vendas
Um sistema desktop minimalista desenvolvido para automatizar e centralizar o registro de vendas diárias. O projeto substitui controles manuais por uma interface gráfica intuitiva que realiza o cálculo automático do faturamento em tempo real, utilizando um banco de dados integrado para garantir a segurança e o histórico das operações. É uma solução focada em eficiência operacional e gestão estratégica corporativa.

🔌 Como fazer funcionar na sua máquina:

Instale o Python na sua máquina (certifique-se de marcar a opção "Add Python to PATH" durante a instalação);

Faça o download ou clone este repositório no seu computador;

Não é necessário instalar bibliotecas externas, pois o projeto utiliza apenas pacotes nativos do Python.

Abra o terminal na pasta do projeto e execute o comando: python main.py (ou o nome que você deu ao arquivo do código).

📋 Pré-requisitos do sistema:

Sistema Operacional: Windows, macOS ou distribuições Linux com suporte a interface gráfica.

Espaço em disco: Menos de 10MB.

Permissão de leitura e escrita na pasta (para a criação automática do arquivo do banco de dados .db).

🛠️ Tecnologias utilizadas:

Editor de código: Visual Studio Code (VS Code) / PyCharm

Linguagens: Python e SQL (para estruturação do banco de dados)

Bibliotecas: * tkinter e ttk (Interface Gráfica UI/UX)

sqlite3 (Persistência e Banco de Dados)

datetime (Automação de data e hora)
